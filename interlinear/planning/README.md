# Vocabulary for the remaining Athens books

These tables measure coverage at Athens commit `9bcd386`, when Genesis and Psalms 21, 22 and 50 had English glosses. Of 566,625 remaining word occurrences, 417,690 share a spelling with a reviewed Athens word. Another 56,110 have a Greek New Testament match in the Berean workbook. The other 92,825 need a fresh lookup.

- [Book coverage](book-coverage.tsv) counts occurrences. Each remaining word falls in one column. An existing Athens analysis takes priority over a Berean candidate.
- [Shared forms](shared-forms.tsv) ranks exact spellings that had no reviewed Athens occurrence. The book count shows where one vocabulary decision could help several books.
- [Berean candidates](berean-candidates.tsv) lists each matching spelling and each distinct Strong’s number and parse recorded for it, with one New Testament reference and its Berean English. Case and accents are significant. Canonically equivalent Unicode spellings match.

The workbook is the publisher’s BSB translation table. The comparison uses the Greek base form in column F, parsing in I, Greek Strong’s number in L, verse reference in M and English in S.
